# Netease-ccuipacks Cleaning

一个用于 **CCUI 资源文件压缩与清理** 的 Python 工具。

通过 FFmpeg 对netease-ccuipacks资源文件进行优化，同时保留原有文件结构，并支持批量并行处理。

## 压缩效果

以 **3.9.5.297103** 版本为例：

| | 文件大小 |
|---|---:|
| 压缩前 | **1.27 GB**（1,368,150,016 Bytes） |
| 处理后 | **102 MB**（107,009,002 Bytes） |





文件共减少：

**1,261,141,014 Bytes**

体积缩小：**92.18%**

也就是说，处理后的文件仅约为原始文件大小的 **7.82%**。

## 使用

首先确保系统中可以正常运行 FFmpeg：

```bash
ffmpeg -version
```
如果没有，请前往https://ffmpeg.org/获取程序
然后运行：

```bash
python ccui_cleaning.py
```

按照提示依次选择：

1. FFmpeg 路径
2. 目标文件夹
3. 输出文件夹
4. 是否清理 `.2` 文件
5. 并发线程数

如果 FFmpeg 已经加入系统 `PATH`，FFmpeg 路径直接回车即可。

## ⚠️ 注意

- 建议将输出目录设置为新的目录，不要直接覆盖原始资源。
- `.2` 文件清理属于实际删除操作，请确认后再执行。
- 压缩效果会根据具体资源内容有所不同，以上数据为 **3.9.5.297103** 的实际测试结果。
